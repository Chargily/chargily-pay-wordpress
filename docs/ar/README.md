# Chargily Pay™ V2

- الحد الأدنى للإصدار المطلوب: 2.0.0  
- تم اختبار WordPress حتى: 6.9.4  
- تم اختبار WooCommerce حتى: 10.6.1  
- النسخة المستقرة: 2.5.30  
- يتطلب PHP: 7.0  
- الترخيص: GPLv2  
- رابط الترخيص: [رابط الترخيص](https://www.gnu.org/licenses/gpl-2.0.html)

إضافة **WooCommerce** لبوابة الدفع **Chargily Pay™ - V2**.

أسهل طريقة مجانية لدمج واجهة برمجة تطبيقات الدفع الإلكتروني (API) عبر بطاقات **EDAHABIA** التابعة لـ **بريد الجزائر** وبطاقات **CIB** التابعة لـ **SATIM** داخل منصة **WooCommerce / WordPress** الخاصة بك.

<p align="center"><img src="https://i.imgur.com/Sca0nNJ.png"></p>

يمكنك بسهولة قبول المدفوعات من عملائك باستخدام بطاقات **EDAHABIA** و **CIB**.

## كيفية استخدام الإضافة؟

1. قم بتحميل أحدث نسخة من هذا الرابط:  [Chargily Pay™ for Wordpress/WooCommerce](https://github.com/Chargily/chargily-pay-wordpress/releases "Chargily Pay for Wordpress/WooCommerce") 
2. قم بتثبيت الإضافة وتفعيلها.
3. أنشئ حسابًا على [Chargily Pay™](https://pay.chargily.com/dashboard/register)
4. احصل على مفاتيح **API** الخاصة بك من هنا: [API keys](https://dev.chargily.com/pay-v2/api-keys)  
5. أدخل مفاتيح **API** في إعدادات الإضافة.

## الدعم الفني

يمكنك الحصول على الدعم عبر واتساب:
